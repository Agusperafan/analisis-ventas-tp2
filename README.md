# Análisis de Ventas

## Descripción del Proyecto
Trabajo Práctico de Gestión Colaborativa correspondiente a la materia de Organización Empresarial - UTN Tecnicatura Universitaria en Programación a Distancia (TUPaD).
El proyecto analiza un conjunto de datos (de muestra) de ventas comerciales para generar indicadores básicos.

## Escenario Elegido
**Escenario B – Análisis de Ventas de una Pequeña Empresa**

## Dataset Utilizado
Dataset simulado de ventas comerciales con registros de producto, cantidad vendida, precio y fecha de venta.

## Estructura del Repositorio
repo/
├── datos/        → Archivos CSV con los datos de ventas
├── scripts/      → Script Python de análisis
├── resultados/   → Gráficos y resultados generados
├── README.md     → Documentación del proyecto
└── .gitignore    → Archivos excluidos del repositorio

## Instrucciones para Ejecutar
1. Abrir Google Colab
2. Clonar el repositorio
3. Ejecutar el script `scripts/analisis_ventas.py`
4. Los resultados se guardan automáticamente en `/resultados`
